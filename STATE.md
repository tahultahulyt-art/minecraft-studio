# Minecraft Studio — current state (v0.1)

Rebuilt from Rahul's earlier editor codebase (his own project, backed up before the old repo was deleted). Rebranded to Minecraft Studio with an original green theme and a new Home layout inspired by his reference screenshot (layout only — all branding, colors, icons and names are original).

## Real features
- Video/photo import, timeline editing, trim/split, speed
- Text overlays, music + volume, filters/effects, transitions
- Templates/styles panel
- Optional Gemini-powered captions and background removal (user's own free API key)
- On-device export (ffmpeg.wasm), rendered preview
- Project save/load on device, portable .mcs backup/restore
- Undo/redo, frame stepping, crash-recovery journal
