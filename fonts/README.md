# Fonts

AlyaMixed-Regular.ttf is a renamed derivative merging the bundled Noto Sans
Devanagari and Noto Sans Regular fonts with fontTools.merge. It keeps Devanagari
shaping and adds Latin glyphs for mixed-script text layers in ffmpeg, where
browser font fallback is unavailable. No original reserved font names are used
for the derivative family.
