Refine transparent image edges
Works on PNG/cutout transparency, not opaque photo background removal. Shrink trims a few image pixels; feather softens alpha edges. Each apply changes this layer image; Undo restores it. Does not fix missing hair or choose an object.
Experimental patch tracking
Move this layer's X/Y onto a small textured detail in the video at layer start. Track uses8 sampled frames, up to8s, inside one video clip. No AI/object recognition, scale/rotation or occlusion recovery. Repeated patterns/fast moves can drift. Replaces existing motion points. Review all points before keeping them; Undo available.
Up to 8 position/size/rotation points. Time is seconds from layer start. Preview/export share interpolation; smooth ease slows at each point. Size/angle can change per point. Animated size/rotation needs more memory; use short clips and480p on slow devices. Old End X/Y controls work when custom points are reset.
Chroma key removes one color from an imported image layer. Not AI background removal; For video solid-color keying use Clip tools. This image-layer preview shows the original image; rendered preview shows the key.
